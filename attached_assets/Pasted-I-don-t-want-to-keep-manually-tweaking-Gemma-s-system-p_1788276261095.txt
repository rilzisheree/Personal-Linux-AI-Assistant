FUNCTION should take priority when the user wants Luna to interact with or retrieve live information from the computer.

REASONING should take priority when the request requires meaningful analysis, planning, coding, multi-step reasoning, or detailed generation.

SIMPLE should ONLY be used for genuinely trivial requests.

When uncertain between SIMPLE and REASONING, prefer REASONING.
